# 診間語音

適合 iPad 的繁體中文語音卡片。24 句台詞使用預先產生的台灣華語低沉男聲 MP3，不依賴裝置的系統語音。

## 使用

卡片依看診流程分成「開場與問診、安排檢查、說明結果、治療處置、返家與收尾」，自我介紹放在第一張。上方分類列可直接跳到各區，捲動時仍可使用。卡片編號依顯示順序排列；文字與原音檔對應不變。

點一下卡片播放；播放中點選其他卡片會依序加入待播，原句播完後自動接續（iPad 上整頁第一句系統語音若接在卡片後面，Safari 會要求點一下底部「繼續播放」才開始，之後就會自動接續）。同一張連點多次也會依次播放，卡片顯示候播順序，底部顯示待播句數。底部「停止並清空」、Escape 或切換至背景都會停止發聲並清空待播。播放設定可調整語速，以及卡片與合成語音的音量，支援鍵盤 Tab、Enter。若音檔載入或播放失敗，會顯示提示並清空待播，重新點選即可再試。

「自由輸入」預設收起，點「自由輸入」可展開；收合會保留草稿。展開後可輸入臨時要說的話，按「加入播放」與固定卡片共用同一個待播順序。每次送出都保留當時文字及所選聲音，之後修改／清除草稿不影響待播。草稿不儲存到 localStorage、網址或網站伺服器；只記住聲音選擇及播放設定。Enter 可換行，送出請按按鈕。

自由輸入預設「超文」：隨網站提供的 sherpa-onnx 2.0.0 WebAssembly 引擎與 Piper 超文模型（國語女聲，22.05 kHz，大陸口音）在 Web Worker 內即時合成 WAV，再透過與固定卡片相同的播放器出聲，文字不會離開裝置。第一次連網開啟會在 Service Worker 就緒後自動下載引擎與模型約 33 MB（聲音選單下方顯示進度），之後由快取供應；引擎就緒前「加入播放」與「試聽」暫停使用，請先用固定卡片。若 Service Worker 遲遲未接管（例如安裝失敗），30 秒後仍會開始下載，只是這次不進離線快取。合成前會先做文字正規化：全形數字、小數點、字母、％、＜＞轉成半形，千分位逗號去掉，「50%」改寫成「百分之50」（「50-60%」改成「百分之50到60」），「℃」「°」改寫成「度」，「3~5」改成「3到5」，「3:30」改成「3點30分」，＞＜≥≤± 改成大於、小於、大於等於、小於等於、正負，7 位以上的數字串（電話）逐字唸，mg、kg、ml、cm、mm、mmHg、μg、bpm 改成中文單位，再把其餘英文字母改寫成國語讀音（X → 艾克斯），最後用 opencc-js 做字級繁轉簡，因為模型詞典的多字詞只有簡體（「音樂、銀行、長大、還是」直接送繁體會念錯）；數字由引擎內建規則轉成中文讀法。「1/2」會被唸成「一、二」，分數請改寫成「半顆」之類的說法。引擎無法朗讀的字元（括號、引號等標點除外）會被略過，播放列會在句尾標示「無法朗讀」。「停止並清空」不會中斷正在合成的句子，下一句要等它合成完才開始（通常一兩秒）。引擎載入失敗時會先改用起始記憶體 128 MB 的縮減版 wasm 重試（這個檔案只在需要時下載，離線時若標準版失敗就無法重試），再失敗就自動改選「備用機械語音」並在聲音狀態列顯示原因；已排入待播的自由輸入也會改用備用機械語音。2026-10-24 在 iPad Pro（第三代 11 吋）iPadOS 27.0.1 Safari 以 [neural-preview.html](neural-preview.html) 實測：標準 512 MB 版載入 1.2 秒、有聲且清晰。

聲音選單可改選裝置內建的中文 SpeechSynthesis 語音（Safari 為「美佳」，台灣華語女聲，聲線與固定卡片的男聲不同），文字同樣不會送到外部語音服務；選單只列出裝置本機的國語語音（排除粵語），依台灣華語、繁體中文、其他中文排序。選過的聲音會記住；若裝置沒有該聲音，退回超文。2026-10-24 在 iPad Pro（第三代 11 吋）Safari 實測，系統語音含英文全部有事件但無聲，原因未明，所以預設不用它。系統語音保留裝置預設音高與音量，音量請用裝置音量鍵調整；網站音量滑桿控制固定卡片與兩種合成語音。聲音選單旁的「試聽」會用目前選的聲音唸「你好，請稍等。」，看診前先按一次確認聽得到，也讓 iPad Safari 之後接在卡片後的句子不必再點「繼續播放」。若 Safari 擋下朗讀或遲遲沒有開始，底部會出現「繼續播放」，點一下會重試這句並保留其餘待播。Safari 只把 iPadOS 內建的 compact 語音提供給網頁；在設定裡另外下載的高音質語音或 Siri 語音不會出現在選單（WebKit 限制）。iPad 開啟「鎖定模式」時語音朗讀功能會被停用，兩種合成語音所需的 WebAssembly 通常也會被擋，只剩固定卡片可用。本版在 macOS Safari 與 Chromium 實測；正式頁的超文整合在 iPad 實機待確認。

iPad 上系統語音若顯示「正在朗讀」卻沒有聲音（2026-10-22 與 10-24 在 iPad Pro 實測美佳、婷婷、英文皆如此，[voice-check.html](voice-check.html) 六種變因全無聲，原因未查明），依序檢查：控制中心的靜音模式是否關閉、「設定 › 聲音」的音量是否調高、「設定 › 輔助使用 › 語音內容 › 聲音」裡的中文（台灣）美佳能否試聽、是否開啟鎖定模式；重新載入頁面後先按「試聽」，再比較先點過卡片之後是否仍有聲。都沒聲就改回「超文」或「備用機械語音」。

「備用機械語音」使用隨網站提供的 Spellophone / eSpeak NG 中文引擎在 Web Worker 內產生 WAV，再透過與固定卡片相同的播放器出聲。聲調與斷句常不準，但在 iPad 上確定有聲。停止並清空會中止尚未完成的合成，已產生的暫存音檔播放完或停止後即釋放。若 Safari 阻止首次自動播放，點底部「繼續播放」會直接播放已合成的音檔，保留其餘待播。

第一次連網載入後，Service Worker 快取頁面、固定音檔及備用語音引擎（網站改版時整批換新）；超文的引擎與模型檔在第一次載入時另存到獨立快取 `clinic-voice-cards-neural-v1`，網站改版不會重新下載。都快取完成後可離線使用（瀏覽器可能自行清除快取）。iPad Safari 可用分享選單加入主畫面。

頁尾的離線提示有三種：「卡片與語音引擎已備妥 · 可離線使用」表示固定卡片、備用語音引擎與超文的檔案都已快取；「卡片已備妥 · 語音引擎下載完成後可離線使用」表示選的是超文但它的檔案尚未快取齊全；「卡片與備用語音已備妥 · 可離線使用」表示目前選的是其他聲音、超文的檔案尚未快取。超文、備用機械語音與系統語音都不需要連線即可朗讀新句子；系統語音取決於裝置提供的聲音是否可用。

## 開發與部署

純 HTML、CSS、JavaScript，無需建置。以 `python3 -m http.server 8765` 預覽，GitHub Pages 使用 main 分支根目錄。

[新版語音試聽](voice-preview.html) 提供本機產生的 MeloTTS 中文聲音及 Kokoro `zm_yunjian` 男聲，可切換同句音檔比較。Melo 音檔僅調整固定增益以接近男聲音量，未改語速或音高。這些預錄短句供使用者評估清晰度與自然度，不代表即時合成已整合或已通過 iPad 測試。試聽頁不載入語音模型；正式自由輸入預設使用超文，另可選裝置語音與備用機械語音。

語音生成方式見 `tools/generate_audio.py`；固定使用 Microsoft `zh-TW-YunJheNeural` 男聲，稍慢語速與降低音高。語音檔不包含任何實際病人資料。使用時不呼叫語音生成服務。

[離線神經語音試點](neural-preview.html) 是比較與量測頁，用同一個 Worker 引擎（[neural-tts-worker.js](neural-tts-worker.js)）可選超文或 AISHELL-3（icefall VITS，8 kHz，174 位說話者，Apache-2.0，約 44 MB；2026-10-24 iPad 試聽判定口音太重、聽不太懂），並顯示下載大小、載入與合成耗時及每一步的文字；加上 `?autotest=1`（可配 `&model=aishell3`、`&wasm=lowmem`）會自動載入並合成三句。超文的檔案與正式頁共用快取，AISHELL-3 不快取。超文授權邊界未釐清，見 THIRD_PARTY.md。
