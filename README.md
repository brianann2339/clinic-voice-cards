# 診間語音

適合 iPad 的繁體中文語音卡片。24 句台詞使用預先產生的台灣華語低沉男聲 MP3，不依賴裝置的系統語音。

## 使用

卡片依看診流程分成「開場與問診、安排檢查、說明結果、治療處置、返家與收尾」，自我介紹放在第一張。上方分類列可直接跳到各區，捲動時仍可使用。卡片編號依顯示順序排列；文字與原音檔對應不變。

點一下卡片播放；播放中點選其他卡片會依序加入待播，原句播完後自動接續（iPad 上整頁第一句系統語音若接在卡片後面，Safari 會要求點一下底部「繼續播放」才開始，之後就會自動接續）。同一張連點多次也會依次播放，卡片顯示候播順序，底部顯示待播句數。底部「停止並清空」、Escape 或切換至背景都會停止發聲並清空待播。播放設定可調整語速，以及卡片與備用語音的音量，支援鍵盤 Tab、Enter。若音檔載入或播放失敗，會顯示提示並清空待播，重新點選即可再試。

「自由輸入」預設收起，點「自由輸入」可展開；收合會保留草稿。展開後可輸入臨時要說的話，按「加入播放」與固定卡片共用同一個待播順序。每次送出都保留當時文字及所選聲音，之後修改／清除草稿不影響待播。草稿不儲存到 localStorage、網址或網站伺服器；只記住聲音選擇及播放設定。Enter 可換行，送出請按按鈕。

自由輸入預設「備用機械語音」。聲音選單可改選裝置內建的中文 SpeechSynthesis 語音（Safari 為「美佳」，台灣華語女聲，聲線與固定卡片的男聲不同），文字同樣不會送到外部語音服務；選單只列出裝置本機的國語語音（排除粵語），依台灣華語、繁體中文、其他中文排序。選過的聲音會記住；若裝置沒有該聲音，退回備用機械語音。2026-10-24 在 iPad Pro（第三代 11 吋）Safari 實測，系統語音含英文全部有事件但無聲，原因未明，所以預設不用它。系統語音保留裝置預設音高與音量，音量請用裝置音量鍵調整；網站音量滑桿控制固定卡片與備用語音。聲音選單旁的「試聽」會用目前選的聲音唸「你好，請稍等。」，看診前先按一次確認聽得到，也讓 iPad Safari 之後接在卡片後的句子不必再點「繼續播放」。若 Safari 擋下朗讀或遲遲沒有開始，底部會出現「繼續播放」，點一下會重試這句並保留其餘待播。Safari 只把 iPadOS 內建的 compact 語音提供給網頁；在設定裡另外下載的高音質語音或 Siri 語音不會出現在選單（WebKit 限制）。iPad 開啟「鎖定模式」時語音朗讀功能會被停用，備用引擎所需的 WebAssembly 通常也會被擋，只剩固定卡片可用。本版在 macOS Safari 與 Chromium 實測，iPad 實機行為待確認。

iPad 上系統語音若顯示「正在朗讀」卻沒有聲音（2026-10-22 與 10-24 在 iPad Pro 實測美佳、婷婷、英文皆如此，[voice-check.html](voice-check.html) 六種變因全無聲，原因未查明），依序檢查：控制中心的靜音模式是否關閉、「設定 › 聲音」的音量是否調高、「設定 › 輔助使用 › 語音內容 › 聲音」裡的中文（台灣）美佳能否試聽、是否開啟鎖定模式；重新載入頁面後先按「試聽」，再比較先點過卡片之後是否仍有聲。都沒聲就改選「備用機械語音」。

「備用機械語音（相容模式）」使用隨網站提供的 Spellophone / eSpeak NG 中文引擎在 Web Worker 內產生 WAV，再透過與固定卡片相同的播放器出聲。聲調與斷句常不準，但在 iPad 上確定有聲。停止並清空會中止尚未完成的合成，已產生的暫存音檔播放完或停止後即釋放。若 Safari 阻止首次自動播放，點底部「繼續播放」會直接播放已合成的音檔，保留其餘待播。

第一次連網載入後，Service Worker 快取頁面、固定音檔及備用語音引擎，可供離線使用（瀏覽器可能自行清除快取）。iPad Safari 可用分享選單加入主畫面。

離線提示確認固定卡片及備用語音引擎已快取。系統語音與備用引擎都不需要連線即可朗讀新句子；系統語音取決於裝置提供的聲音是否可用。

## 開發與部署

純 HTML、CSS、JavaScript，無需建置。以 `python3 -m http.server 8765` 預覽，GitHub Pages 使用 main 分支根目錄。

[新版語音試聽](voice-preview.html) 提供本機產生的 MeloTTS 中文聲音及 Kokoro `zm_yunjian` 男聲，可切換同句音檔比較。Melo 音檔僅調整固定增益以接近男聲音量，未改語速或音高。這些預錄短句供使用者評估清晰度與自然度，不代表即時合成已整合或已通過 iPad 測試。試聽頁不載入語音模型；正式自由輸入使用上述裝置語音與備用引擎。

語音生成方式見 `tools/generate_audio.py`；固定使用 Microsoft `zh-TW-YunJheNeural` 男聲，稍慢語速與降低音高。語音檔不包含任何實際病人資料。使用時不呼叫語音生成服務。

[離線神經語音試點](neural-preview.html) 是獨立的實驗頁，尚未整合進自由輸入，也不在 Service Worker 的離線預載內。它在瀏覽器 Worker 內以 sherpa-onnx 2.0.0 的 WebAssembly 引擎即時合成國語 WAV，再用一般 `<audio>` 播放；文字不會離開裝置。可選兩個模型：超文 chaowen（Piper VITS int8，22.05 kHz，連引擎第一次約下載 33 MB；授權邊界未釐清，見 THIRD_PARTY.md）與 AISHELL-3（icefall VITS，8 kHz，174 位說話者，Apache-2.0，約 44 MB）。合成前會把英文字母改寫成國語讀音、再用 opencc-js 做字級繁轉簡，因為模型詞典的多字詞只有簡體（「音樂、銀行、長大、還是」直接送繁體會念錯）；數字由引擎內建規則轉成中文讀法。頁面提供三個固定測試句與自由輸入，並顯示下載大小、載入與合成耗時；加上 `?autotest=1`（可配 `&model=aishell3`、`&wasm=lowmem`）會自動載入並合成三句。`wasm=lowmem` 使用起始記憶體 128 MB 的修改版 wasm，供標準版在 iPad 上載入失敗時備用。本頁在 macOS Safari 與 Chromium 實測可合成，iPad 實機與人耳評估待確認。
