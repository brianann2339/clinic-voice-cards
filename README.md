# 診間語音

適合 iPad 的繁體中文語音卡片。24 句台詞使用預先產生的台灣華語低沉男聲 MP3，不依賴裝置的系統語音。

## 使用

卡片依看診流程分成「開場與問診、安排檢查、說明結果、治療處置、返家與收尾」，自我介紹放在第一張。上方分類列可直接跳到各區，捲動時仍可使用。卡片編號依顯示順序排列；文字與原音檔對應不變。

點一下卡片播放；播放中點選其他卡片會依序加入待播，原句播完後自動接續。同一張連點多次也會依次播放，卡片顯示候播順序，底部顯示待播句數。底部「停止並清空」、Escape 或切換至背景都會停止發聲並清空待播。播放設定可調整語速與音量，支援鍵盤 Tab、Enter。若音檔載入或播放失敗，會顯示提示並清空待播，重新點選即可再試。

第一次連網載入後，Service Worker 快取頁面及全部語音，可供離線使用（瀏覽器可能自行清除快取）。iPad Safari 可用分享選單加入主畫面。

## 開發與部署

純 HTML、CSS、JavaScript，無需建置。以 `python3 -m http.server 8765` 預覽，GitHub Pages 使用 main 分支根目錄。

語音生成方式見 `tools/generate_audio.py`；固定使用 Microsoft `zh-TW-YunJheNeural` 男聲，稍慢語速與降低音高。語音檔不包含任何實際病人資料。使用時不呼叫語音生成服務。
