# 診間語音

適合 iPad 的繁體中文語音卡片。24 句台詞使用預先產生的台灣華語低沉男聲 MP3，不依賴裝置的系統語音。

## 使用

卡片依看診流程分成「開場與問診、安排檢查、說明結果、治療處置、返家與收尾」，自我介紹放在第一張。上方分類列可直接跳到各區，捲動時仍可使用。卡片編號依顯示順序排列；文字與原音檔對應不變。

點一下卡片播放；播放中點選其他卡片會依序加入待播，原句播完後自動接續。同一張連點多次也會依次播放，卡片顯示候播順序，底部顯示待播句數。底部「停止並清空」、Escape 或切換至背景都會停止發聲並清空待播。播放設定可調整語速，以及卡片與相容語音的音量，支援鍵盤 Tab、Enter。若音檔載入或播放失敗，會顯示提示並清空待播，重新點選即可再試。

「自由輸入」預設收起，點「自由輸入」可展開；收合會保留草稿。展開後可輸入臨時要說的話，按「加入播放」與固定卡片共用同一個待播順序。每次送出都保留當時文字及所選聲音，之後修改／清除草稿不影響待播。草稿不儲存到 localStorage、網址或網站伺服器；只記住聲音選擇及播放設定。Enter 可換行，送出請按按鈕。

自由輸入預設「本機合成（相容模式）」，使用隨網站提供的 Spellophone / eSpeak NG 中文引擎在 Web Worker 內產生 WAV，再透過與固定卡片相同的播放器出聲。聲音較機械，與固定卡片的預錄男聲不同；文字不會送到外部語音服務。停止並清空會中止尚未完成的合成，已產生的暫存音檔播放完或停止後即釋放。若 Safari 阻止首次自動播放，點底部「繼續播放」會直接播放已合成的音檔，保留其餘待播。

聲音選單仍可選擇裝置提供的本機中文 SpeechSynthesis 語音。若 iPad 使用系統語音無聲，選回「本機合成（相容模式）」。系統語音保留裝置預設音高與音量，音量請用裝置音量鍵調整；網站音量滑桿控制固定卡片與相容語音。

第一次連網載入後，Service Worker 快取頁面、固定音檔及本機合成引擎，可供離線使用（瀏覽器可能自行清除快取）。iPad Safari 可用分享選單加入主畫面。

離線提示確認固定卡片及相容語音引擎已快取。相容模式不需要連線即可合成新句子；選用系統語音時仍取決於裝置提供的聲音是否可用。

## 開發與部署

純 HTML、CSS、JavaScript，無需建置。以 `python3 -m http.server 8765` 預覽，GitHub Pages 使用 main 分支根目錄。

[新男聲試聽](voice-preview.html) 僅提供本機產生的 Kokoro `zm_yunjian` 預錄短句，供使用者評估清晰度，不代表即時合成已整合或已通過 iPad 測試。試聽頁不載入語音模型；正式自由輸入仍使用上述 v11 引擎。

語音生成方式見 `tools/generate_audio.py`；固定使用 Microsoft `zh-TW-YunJheNeural` 男聲，稍慢語速與降低音高。語音檔不包含任何實際病人資料。使用時不呼叫語音生成服務。
